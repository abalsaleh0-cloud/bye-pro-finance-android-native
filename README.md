# BYE PRO Finance — Native Android

Standalone Kotlin/Android implementation. This repository contains the Native Android project extracted from the `native-android` directory of `bye-pro-finance-android-flutter`, branch `feature/native-android-rebuild`.

The Flutter repository remains separate and unchanged. Native Android development continues here.

## Build

Open this repository in Android Studio and sync the Gradle project. Use the included Gradle configuration and Android SDK.
